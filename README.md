One technical concept that I developed greater mastery over in this project was CSS animations using `@keyframes`. At first animations felt confusing, but over time I started to understand them as an element that moves or changes from start to finish.

My mental model for `@keyframes` is that they don’t target anything by themselves. Instead they describe how an animation should behave and only **elements** that reference those **keyframes** using the `animation` property are affected. This helped me understand why animations wouldn’t run unless I explicitly applied them to an element.

I used @keyframes in my project to animate how content appears when the page loads. One example of this is when I created an animation that slide the navigation bar down from the top and fades in all sections into view as the site loads in. This made the website feel smoother and more polished while helping me better understand how animations work when working with CSS/HTML.

One part of this project that I found challenging but am really proud of was adding animations and hover effects without breaking the layout of the website. At first, it was hard to get everything to move smoothly while keeping the site clean and readable, especially with a fixed navbar and multiple sections.

Another part of this project that I found challenging was preventing the navigation bar from covering content when using the navigation links, I fixed this by adding top padding to the page and using CSS scroll-margin-top so the sections wouldn’t scroll underneath the navbar.
